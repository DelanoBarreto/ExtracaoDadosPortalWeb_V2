# Catálogo Prático de Skills

Atualizado em 2026-06-30.

Use este arquivo como atalho para escolher a skill certa sem perder tempo.

Observação: a origem foi resumida no topo para não repetir os nomes dos projetos em cada linha.

## Escolha Rápida

- Precisa descobrir qual skill usar: `/ajuda`, `/guia`, `/roteador`
- Vai organizar trabalho ou escrever plano: `/planejamento`, `/plan-writing`, `/documentacao`
- Vai mexer em tela, layout ou UI: `/frontend`, `/frontend-design`, `/design`, `/web-design-guidelines`
- Vai mexer em API, banco ou integração: `/backend`, `/api-patterns`, `/database-design`, `/supabase`
- Vai testar, validar ou depurar: `/debug`, `/testes`, `/qa-automacao`, `/systematic-debugging`, `/lint-and-validate`
- Vai revisar risco, segurança ou PR: `/revisao`, `/seguranca`, `/code-review-checklist`
- Vai atuar em GitHub, deploy ou operação: `/github-ci`, `/deployment-procedures`, `/server-management`
- Vai trabalhar com performance: `/performance`, `/performance-profiling`, `/react-best-practices`
- Vai trabalhar com jogos: `/game-development`, `/2d-games`, `/3d-games`, `/web-games`
